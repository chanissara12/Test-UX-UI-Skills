# Design system

Three visual sets for the same software landing page and product catalog. Each has its own design doc, generated from its `tokens.css`.

| Set | Brand (fictional) | Style | Doc |
|---|---|---|---|
| A | Northwind | Professional modern, blue | [set-a/design.md](set-a/design.md) |
| B | Lumen | Swiss / minimal, monochrome + pink | [set-b/design.md](set-b/design.md) |
| C | Blockwise | Soft brutalist, warm paper + pink | [set-c/design.md](set-c/design.md) |

All sets share the same three-layer token architecture (primitive → semantic → component) and the same spacing and type scales. Sets B and C also share structure in `shared/`.
